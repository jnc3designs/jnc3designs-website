# Live Data Roadmap

## Vision

Mission Control should display real-time business information instead of demo data.

## Phase 1 – Bambu Printers
Status
Current Job
Progress
Remaining Time
Current Layer
Temperatures
AMS Slot
Loaded Filament
Printer Health

## Phase 2 – Orders
Website Orders
Square Orders
Quote Requests
Customer Responses

## Phase 3 – Inventory
Live filament quantities
Automatic stock updates
Purchase history
Restock suggestions

## Phase 4 – Marketing
Upcoming markets
Facebook schedule
Instagram schedule
EDDM campaigns
Website analytics
Google Business insights

## Guiding Principles

- Real data over placeholder data
- Build once. Improve forever.
- Every integration must improve daily operations.
- One source of truth for each type of business data.
