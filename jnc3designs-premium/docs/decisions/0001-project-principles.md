# ADR-0001 — Project Principles

Date: 2026-07-22

## Status

Accepted

## Context

JNC OS is expected to grow over many years and integrate multiple systems.

## Decision

The repository—not conversation history—is the permanent source of project knowledge.

Business workflows take priority over visual enhancements.

Documentation is updated with every completed Forge.

Features should enhance existing business objects instead of creating isolated systems.

## Consequences

Future contributors can understand why architectural decisions were made.

Project continuity is preserved across chats and devices.
